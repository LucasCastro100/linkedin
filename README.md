# LinkedIn — Material de Perfil e Vagas

Pasta com material em **Markdown** para montar, otimizar e manter o perfil do LinkedIn de **Lucas Henrique de Castro Oliveira** — foco em atração de recrutadores (CLT/efetivo) e oportunidades de **freelance**, incluindo versões em inglês para vagas internacionais.

Não é um projeto de código: são documentos de texto para consultar, copiar e colar diretamente no LinkedIn. Não há build, dependências nem variáveis de ambiente.

## Arquivos

| Arquivo | O que é | Como usar |
|---|---|---|
| [`linkedin-perfil.md`](linkedin-perfil.md) | **Textos prontos para colar** no perfil: título (headline), seção "Sobre" (o que faço + projetos em destaque), sugestões de Destaques, descrição de experiência e skills | Cole cada seção no LinkedIn em *Editar perfil* → *Adicionar seção* |
| [`linkedin-titulos-opcoes.md`](linkedin-titulos-opcoes.md) | **Catálogo de títulos (headline)** organizado por objetivo: diretos, com palavras-chave de stack (ATS), com foco em delivery, por nicho, freelance, criativos, formais/CLT e em inglês + guia de como escolher | Escolha um, cole no campo **Título** (lápis ✏️ ao lado do nome) |
| [`linkedin-titulos-freelancer.md`](linkedin-titulos-freelancer.md) | **Títulos em português para freelancer + atuante na área** — categorias: freela + experiência, atuante, nichos, CTA/available, com personalidade | Use para posição de freelance/adesão a projetos |
| [`linkedin-titulos-freelancer-english.md`](linkedin-titulos-freelancer-english.md) | **Mesma ideia em inglês** para vagas remotas internacionais, com instruções em português de onde colar (os textos entre aspas é o que vai para o LinkedIn) | Perfil global / recrutadores de fora |
| [`linkedin-guia-passo-a-passo.md`](linkedin-guia-passo-a-passo.md) | **Guia de edição ponto a ponto** (12 pontos: foto, banner, título, sobre, experiência, educação, skills, destaques, certificações, idiomas, URL, aberto a recrutadores) + **dois textos completos de "Sobre"** (versão curta e versão longa) | Siga na ordem; cada ponto = um clique no LinkedIn |
| [`linkedin-checklist-recruiters.md`](linkedin-checklist-recruiters.md) | **Checklist completo com marcação** (`[x]`) para revisão por recrutadores: 13 seções + checklist final, com a "regra dos 6 segundos" e ativação do modo *Aberto a Recrutadores* | Marque cada item conforme for concluindo |

## Ordem sugerida de uso

1. **`linkedin-guia-passo-a-passo.md`** — para quem está começando do zero (passo a passo de edição).
2. **`linkedin-perfil.md`** — para colar os textos do perfil (Sobre, experiência, skills, destaques).
3. **`linkedin-titulos-opcoes.md`** (+ variações `freelancer` / `freelancer-english`) — para definir a headline.
4. **`linkedin-checklist-recruiters.md`** — revisão final antes de sair procurando vagas.

## Como consultar

```bash
# leitura no terminal
cat linkedin-perfil.md

# ou no seu editor/leitor Markdown favorito
code .   # VS Code, por exemplo
```

Dica: os blocos de texto marcados com <code>```</code> no Markdown são os trechos prontos para copiar e colar.

## Observações

- Os textos fazem referência a uma stack específica (Next.js, Node.js, TypeScript, Python/automação) e trajetória de freelancer desde 2018 — ajuste conforme seu perfil atual.
- Este README é a bússola da pasta; os arquivos `.md` são o conteúdo. Mantenha os links absolutos/relative atualizados ao renomear arquivos.
