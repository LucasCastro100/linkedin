## ⚠️ Regras para não errar

1. **Só use número que você consegue defender.** Se perguntarem "como você contou?", responda.
2. **Nunca invente** usuários, receita, clientes ou prazos — só números de código/processo.
3. **Métrica sem contexto não vende.** Sempre ligue número → problema → resultado.
4. **22, não 23:** o README antigo dizia 23 sistemas, mas no código o "Portal de Arquivos com
   Clientes" está dentro de "Armazenamento em Nuvem". O número correto é **22**.
