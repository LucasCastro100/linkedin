# 🔧 LinkedIn — Guia Ponto a Ponto de Edição + Textos do "Sobre"

> Siga na ordem para não se perder. Cada ponto = um clique no LinkedIn.

---

## 🖱️ PARTE 1 — PASSO A PASSO DE EDIÇÃO

### Ponto 1 — Foto de perfil
1. Abra `linkedin.com` e clique na sua **foto** no menu superior
2. Clique em **"Ver perfil"**
3. Clique na sua **foto grande** (no perfil)
4. Clique em **"Alterar foto"** → **"Fazer upload"**
5. Escolha a imagem no computador → **"Salvar"**

### Ponto 2 — Banner/capa
1. No seu perfil, passe o mouse sobre o **banner** (a imagem grande do topo)
2. Clique no ícone de **câmera 📷** que aparece
3. **"Enviar foto"** → escolha uma imagem 1584×396 px (dica: faça no Canva)
4. **"Salvar"**

### Ponto 3 — Título (headline)
1. No perfil, clique na linha azul com **"Adicionar título"** (ou no lápis ✏️ se já tem)
2. No campo **"Título"**, cole uma das opções abaixo
3. **"Salvar"**

> Opção direta:
> `Full-Stack Developer | Next.js & Node.js | Automação com Python`

### Ponto 4 — Sobre (About)
1. Role até a seção **"Sobre"**
2. Clique no **lápis ✏️** (ou **"Adicionar seção" → "Sobre"**)
3. No campo **"Sobre"**, cole o texto escolhido (curto **ou** longo — Parte 2)
4. **"Salvar"**

> ⚠️ Só aparece **3 primeiras linhas** sem clicar em "…ver mais" — por isso o texto curto também é útil.

### Ponto 5 — Experiência
1. Role até **"Experiência"** → clique no **lápis ✏️**
2. **"Cargo"**: `Desenvolvedor Full-Stack`
3. **"Emprego"**: sua empresa atual (ou `Freelance`)
4. **"Descrição"**: cole o texto da sua vaga (use um dos prontos abaixo)
5. **"Salvar"**
6. Para adicionar vagas antigas: **"Adicionar seção" → "Experiência"**

> Descrição curta pronta para experiência:
> ```
> • Desenvolvimento de aplicações web (front + back) com Next.js, Node.js e TypeScript
> • Interfaces modernas com Tailwind CSS + Framer Motion
> • Automações com Python e n8n
> • Projetos de pensamento computacional para crianças de 3 a 16 anos
> ```

### Ponto 6 — Educação
1. Role até **"Educação"** (ou **"Adicionar seção" → "Educação"**)
2. Preencha escola/curso, curso, período
3. **"Salvar"**

> Se não tem curso superior, adicione cursos livres (Alura, Rocketseat, freeCodeCamp). Perfil sem Educação aparece "incompleto".

### Ponto 7 — Habilidades (Skills)
1. Role até **"Habilidades"** → clique em **"Adicionar skill"**
2. Digite e escolha da lista: `Next.js`, `Node.js`, `TypeScript`, `JavaScript`, `Tailwind CSS`, `Framer Motion`, `Python`, `Laravel`, `NestJS`
3. Clique em **"Salvar"** para cada uma
4. Para **fixar as 3 principais**: passe o mouse sobre a skill → clique na **★ estrela** (as 3 fixadas viram as preferidas)

### Ponto 8 — Destaques (Featured)
1. No topo do perfil, procure a seção **"Recursos"** (ou **"Em destaque"**)
2. Clique em **"Adicionar" → "Links"**
3. **"Título"**: nome do projeto (ex: `Style Hub`)
4. **"URL"**: o link do GitHub
5. **"Descrição"**: uma linha do que é o projeto
6. **"Salvar"** — repita para os 4 projetos

> Links para colar:
> - Style Hub → `https://github.com/LucasCastro100/style-hub`
> - OdontoPro → `https://github.com/LucasCastro100/odontopro`
> - App Finanças → `https://github.com/LucasCastro100/app-financas`
> - Control School → `https://github.com/LucasCastro100/control-school`

### Ponto 9 — Certificações
1. **"Adicionar seção" → "Certificações" → "Certificado"**
2. Preencha nome, **"Emitido por"** e **"ID da credencial"** (se tiver)
3. **"Salvar"**

### Ponto 10 — Idiomas
1. **"Adicionar seção" → "Idiomas"**
2. `Português` → **Nativo** / `Inglês` → seu nível real
3. **"Salvar"**

### Ponto 11 — URL personalizada
1. No seu perfil, clique em **"Editar perfil público e URL"** (na linha com a URL)
2. Em **"Editar sua URL personalizada"**, digite algo limpo
3. **"Salvar"**

> Sugestões: `linkedin.com/in/lucascastro-dev` ou `linkedin.com/in/lucas-oliveira-dev`

### Ponto 12 — Aberto a recrutadores
1. Na sua **foto de perfil** → **"Configurações de procura"** (ou **"Aberto a recrutadores"**)
2. Selecione **"Somente recrutadores"**
3. Defina cargos desejados: `Desenvolvedor Full-Stack`, `Desenvolvedor Front-end`, `Desenvolvedor Back-end`
4. Defina tipo: tempo integral, freelance, remoto
5. **"Salvar"**
